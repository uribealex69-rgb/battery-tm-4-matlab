# MATLAB Project Code Files

This folder contains the main MATLAB project code files, the helper functions, extra backup files, as well as the PDF files of the main/necessary files

## Folder Contents

- [Helper Functions](./Helper%20Functions/)
  - Contains the helper functions used by the main Live Script for plotting charging phases, transition points, power, and energy.
- [PDF Documents](./PDF%20Documents)
  - Contains PDF documents of the completed Live Script (main project) as well as the helper functions
- [Project Data (for code)](./Project%20Data%20(for%20code))
  - Contains the battery dataset used by the code.
- [livescript_versions](./livescript_versions)
  - Contains earlier versions of the Live Script during the development of the project
- Battery_Charging_Profile_TEAM4.mlx
  - The completed main live script which contain the project's required and optional code, as well as the MATLAB Breakdown Questions and Interpretation of Results
